# Work learning round 3

New Scratch drafts may use the native owner relay. Existing local document
threads keep their own provider and thread. A running assistant-backed
composer retains the draft and native Stop. Work uses a reserved native
retry key, the usual launch schema and native title generation.

When the attachment is unavailable, Work dispatches locally against the same
visible thread. The server serializes this dispatch with relay attachment
updates and removes the previous tool routes before the turn. A bound
follow-up shares the same native command receipt across both paths. Work
rotates the attachment on the next eligible idle send under current consent
for the same owner, assistant and Mac. A normal standalone draft stays quiet.

Local tests cover composer eligibility and busy state, a rejected local
dispatch during an active run, detachment, and reattachment with refreshed
native consent. The enrolled Desktop-to-relay path needs signed integration
verification.
