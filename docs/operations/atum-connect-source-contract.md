# Atum Connect source contract

T1 is built and locally verified, not deployed. Source starts at T0 `a4496b0d6` and reuses prior Atum verifier commit `16a10db82`. T0 already merges upstream Connect plus the fork's own-thread runtime. A rebase onto `feat/work-runtime-0.1.15` was attempted and aborted: it replayed 596 upstream commits and encountered an unavailable historical blob; a no-commit merge then showed six provider-related conflicts and was also aborted. No unrelated provider/UI conflict resolutions were folded into T1. Coordinator assembly must preserve both T0 own-thread rules and the current runtime changes.

The native relay remains the control plane; native Cloudflare managed endpoints carry ordinary traffic directly to the environment. The only production changes are the Atum assertion verifier/API input, reusable client identity adapter, trial resource profile, default-on new-device approval and provisioning entrypoint. No networking, auth-session, DPoP, managed allocator, route-driver or MCP stack was reimplemented. MIT copyright and permission notice remain in LICENSE and NOTICE (“Based on T3 Code / T3 Connect”).

The Atum relay accepts only a verified canonical owner assertion from the platform's pinned Ed25519 JWKS, at most 60 seconds old/lifetime, with exact audience/issuer/type and a required nonempty jti. It never falls back to Clerk in Atum mode. Native relay tokens, linking proofs, DPoP replay, environment bootstrap/session, MCP OAuth and revocation remain distinct layers. The native client API's historical `clerkToken` input also accepts this identity assertion; `createAtumConnectIdentity` supplies it and guards account switches.

The existing source own-thread enforcement and handler tests are untouched. A native human Connect session is not an S2 agent grant; agent generation, admission, unknown outcome and settlement remain T3/T4 integration boundaries. Native device approval defaults true, but existing explicitly false settings must be migrated deliberately. Account disable is not synonymous with instant revocation of every previously issued session.

See [the reproducible runbook](atum-connect-runbook.md), [itemised quote](atum-connect-trial-quote.md) and [verification record](atum-connect-verification.md). No push/PR/CI, cloud resource creation, live install changes or provider credentials were part of this worker lane.
