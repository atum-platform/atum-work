# Work runtime 0.1.12

The candidate starts at the bundled 0.1.11 pin and integrates the Work question
toolkit and fenced relay tool scope. Provider settings carry the optional
`showInPicker` flag through to the picker without disabling the provider.
Native Codex and Antigravity authentication use the Work owner view's preload
for browser handoff. Codex waits for the account's custody preflight before
starting authentication. The desktop owns the signed-in account and the
custody endpoint.

The provider screen exposes Claude Code's existing onboarding install/sign-in
terminal. Its links use the owner-view handoff instead of opening the Work
preview. The picker waits for the same Codex preflight before opening setup.
Settings checks it again before starting authentication.

The desktop preload provides `prepareCodexSignIn()` and
`openProviderSignIn(provider, url)`. The first returns true after the
account's un-carry endpoint confirms custody is Work. The second validates
the view, account and maker URL before opening the Mac's default browser.

Focused MCP tests (50), sign-in bridge tests (6), browser picker test (1),
scoped lint and web, server and contracts typechecks passed. Build stopped
before invoking the packer when disk availability fell below 1.5 GiB.
